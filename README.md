# hello-python

My first Python project: greets the user and prints their
name as an ASCII banner (using the open-source pyfiglet library).
It also includes expressions.py, exploring Python expressions,
operators, and Boolean logic. An accompanying Jupyter notebook,
explore.ipynb, repeats the experiments interactively.

Lab 1 – Fundamentals of Computer Programming,
BSc Data Science for Responsible Business.
